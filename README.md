# Instagram Post Maker 📸

An interactive web-based studio to design, customize, preview, and export pixel-perfect Instagram posts and carousel mockups.

## ✨ Features

- **Pixel-Perfect Instagram UI**: Realistic replica of the Instagram post layout (profile headers, carousels, action bars, like counts, captions, and comments).
- **Multiple Post Aspect Ratios**:
  - Square (1:1)
  - Portrait (4:5)
  - Landscape (1.91:1)
- **Multi-Slide Carousel Support**: Add, reorder, delete, and switch slides with smooth navigation.
- **Music & Sound Integration**:
  - Add audio tracks to posts with authentic Instagram header audio tags (`♫ Track Title • Artist Name`) and jumping equalizer bars.
  - Interactive photo speaker button in the bottom-right corner to play, pause, and mute audio with sleek Instagram glassmorphism toast feedback.
  - 5 built-in synthesized aesthetic audio presets (*Lofi Sunset*, *Dream Pop*, *Acoustic Breeze*, *Upbeat Pop*, *Cozy Piano*).
  - Custom audio file upload (MP3, WAV, M4A, OGG, AAC) with automatic Base64 encoding for self-contained exports.
  - Direct audio URL support, in-editor audio player with time scrubber, loop toggle, and volume control.
- **Dynamic Post Date Options**:
  - Custom relative time (e.g. *2 HOURS AGO*)
  - Real-time elapsed timer from creation
  - Custom calendar date & time
- **Interactive Engagements**:
  - Double-tap / click heart animation
  - Like, Comment, Share, Bookmark toggles
  - Custom like counts with formatted numbers
- **Dual Export Options**:
  - 📷 **High-Resolution PNG**: Export static high-res (3x) image snapshot via html2canvas.
  - 💻 **Interactive HTML**: Export standalone, self-contained interactive post files with functioning slide navigation and animations.

## 🚀 Getting Started

No build step or dependencies required. Open `index.html` in any modern web browser to start designing.

```bash
# Clone the repository
git clone https://github.com/MrBlueJr/Instagram-Post-Maker.git

# Navigate into project directory
cd Instagram-Post-Maker

# Open index.html in your browser
```
